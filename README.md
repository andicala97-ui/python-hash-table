This project implements a custom Hash Table data structure in Python using Object-Oriented Programming (OOP).

It demonstrates how hash functions convert keys into numerical values and how key-value pairs are stored, retrieved, and deleted efficiently.

The implementation includes:
- A custom hash function using Python's `ord()` function.
- Insertion of key-value pairs.
- Lookup and retrieval of stored values.
- Removal of key-value pairs.
- Collision handling using separate chaining with nested dictionaries.
- Automatic cleanup of empty buckets after deletion.

The project was developed as a practical exercise in Python programming, data structures, dictionaries, and collision resolution techniques.

**Technologies:** Python 3, Object-Oriented Programming, Dictionaries.
